# Дорожная карта «Конкурса Юджина»

## Статус на 2026-10-27

**Созданы:** открытый репозиторий с первичной концепцией, проектом положения, моделью микроподдержки, оценкой, авторскими правами, безопасностью, демонстрационной страницей, чистыми расчётами и тестами. **Не созданы:** юридически объявленный конкурс, работающая регистрация, приём работ, банковские операции, реальное жюри и выплаты. Не считать опубликованный расчёт юридическим обещанием.

## Этап A — концепция и опыт участия

- [x] Найти художественный первоисточник и сохранить его без редактирования.
- [x] Сформулировать художественные задачи без требуемого мировоззрения.
- [x] Зафиксировать свободный бесплатный вход, запрет преимуществ донорам.
- [x] Проект положения и критериев художественной оценки.
- [x] Зафиксировать границы авторских прав.
- [x] Демонстрационный публичный интерфейс и статический расчёт фонда.
- [ ] Проверить дизайн с реальными художниками, музыкантами и авторами разных стран.
- [ ] Проверить доступность для людей с инвалидностью и пользователей без денег/смартфона.

## Этап B — юридическая и экономическая готовность

- [ ] Определить организатора/юрисдикцию/закреплённые банковские счета, налоговый режим.
- [ ] Согласовать с автором **реальный бюджет и распределение наград**; предлагаемая схема 85/10/5 ещё не утверждена.
- [ ] Назначить независимых операторов оценки и платежей, документировать конфликты интересов.
- [ ] Опубликовать юридически применимое положение (суммы, даты, сроки, место подачи, порядок результатов и апелляций).
- [ ] Проверить возможность крошечных пожертвований у PSP и раскрытие комиссий; выбрать каналы по странам.
- [ ] Подготовить политику конфиденциальности, возрастные сценарии и публикационную лицензию, независимый аудит.

## Этап C — защищённый MVP

- [ ] Создать API приёма работ с hash-квитанцией, защищённым файловым хранилищем и отложенной модерацией.
- [ ] Реализовать независимое удостоверение личности для **получателей призов**, не для каждого творческого участника.
- [ ] Создать панель экспертов, журнал конфликтов интересов, проверяемый подсчёт и безопасное публичное голосование.
- [ ] Отдельный платёжный контур с двумя независимыми подтверждениями, бюджетной резервацией и банковской сверкой.
- [ ] Проверить устойчивость к дубликатам, голосующим ботам, подмене жюри, реквизитов и конкурсных файлов.

## Этап D — публичный пилот

- [ ] Провести маленький пилот **без денежных наград до утверждения условий**, собрать обратную связь.
- [ ] После заключения юриста и готовности фонда — объявить первый реальный денежный сезон.
- [ ] Провести конкурс, независимую оценку, апелляции, подтверждённые выплаты и отчёт.
- [ ] Поддерживать непрерывную открытую галерею, тематические задания, международные соавторства и повторяемые сезоны.

**Не подключать «Солидарность» как автоматический источник средств:** это другой фонд и другие целевые назначения. Возможен только отдельный согласованный, правомерный договор и отдельный учёт.
